Online XSD Viewer

Free online XML Schema (XSD) viewer. Upload an .xsd file, paste the schema source or load it from a URL and explore the schema as an expandable tree, an XMLSpy-style diagram or syntax-highlighted text — including annotations, documentation, appinfo and source line numbers.

Validate XML documents against the schema directly in the browser, or from the command line via the REST validation API (curl, PowerShell, Python). The FundsXML schema releases are built in and can be browsed without uploading anything.
