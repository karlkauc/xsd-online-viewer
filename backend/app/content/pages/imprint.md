## About

The XSD Viewer is a private, open-source project and part of the FreeXmlToolkit family of free tools. It has no
advertising and no paid plans. Voluntary support is possible through GitHub Sponsors. The source code is on
[GitHub](https://github.com/karlkauc/xsd-online-viewer).

The project is independent. It is not affiliated with or endorsed by the W3C, FundsXML or ISO 20022; their names are used only to describe the formats the tool works with.
