[XSDDiagram](https://github.com/dgis/xsddiagram) is a long-standing free tool that draws XML Schema diagrams on
Windows. If you are on macOS or Linux, cannot install software on a work machine, or want to send a colleague a
link instead of a screenshot, the Online XSD Viewer is an alternative:

- **Runs in the browser** — nothing to install; or run it yourself with one Docker command.
- **Diagram in the familiar notation** — sequences, choices, cardinalities, expand and collapse.
- **Multi-file schemas** from a ZIP, with `xs:import`, `xs:include` and `xs:redefine` resolved.
- **Search** across element, type and attribute names, documentation and enumeration values (Ctrl/⌘ + K).
- **Validation** of XML documents against the schema, in the browser or by [REST API](/api-docs).
- **Exports**: PNG, SVG, HTML documentation, sample XML.
- **Links to a node** that open the same schema and selection for anyone.

Both tools are free; use whichever fits your setup. See also the [XSD diagram](/features/diagram) page.
