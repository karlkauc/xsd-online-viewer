FundsXML 4.1.7 was published on 2020-06-15 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.7) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 188, **simple types:** 43, **global elements:** 1

## Changes since FundsXML 4.1.6

### Changed content models

- `AssetManagementCompanyAggregatedType/DiscretionaryMandates/RealAssets/OwnDiscretionaryMandates`
  - added `Property (inline type, 0..1)`
  - changed `Clients: inline type, 1..1 → inline type, 0..1`
  - changed `PortfoliomanagementByThirdParties: inline type, 1..1 → inline type, 0..1`
- `AssetManagementCompanyAggregatedType/DiscretionaryMandates/Securities_Holdings/OwnDiscretionaryMandates`
  - added `Equity (inline type, 0..1)`
  - added `Bonds (inline type, 0..1)`
  - added `Cash_MoneyMarket (inline type, 0..1)`
  - added `PrivateEquity_VentureCapital (inline type, 0..1)`
  - added `HedgeFunds (inline type, 0..1)`
  - added `StructuredProducts (inline type, 0..1)`
  - added `Other (inline type, 0..1)`
  - changed `Clients: inline type, 1..1 → inline type, 0..1`
  - changed `PortfoliomanagementByThirdParties: inline type, 1..1 → inline type, 0..1`
- `CountrySpecificShareClassDataATType`
  - added `TotalNetAssetValue (inline type, 0..1)`
