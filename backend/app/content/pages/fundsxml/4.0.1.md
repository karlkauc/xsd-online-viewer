FundsXML 4.0.1 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.0.1) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 154, **simple types:** 36, **global elements:** 1

## Changes since FundsXML 4.0.0

**Removed types:** `CreditDefaultSwapType`

### Changed content models

- `BondType/Redemption`
  - changed `OptionDirection: anyType, 0..1 → inline type, 0..1`
- `CountrySpecificControlDataATType`
  - added `FundDataPortalInfos (inline type, 0..1)`
- `CountrySpecificFundDataATType`
  - added `FundDataPortalInfos (inline type, 0..1)`
- `EarningType`
  - added `FinallySettled (boolean, 0..1)`
- `FundStaticDataType`
  - added `EndOfFiscalYear (inline type, 0..1)`
- `InvestorType`
  - added `Date (date, 0..1)`
  - removed `NavDate (date, 1..1)`
  - changed `InvestorID: Text256Type, 1..1 → Text256Type, 0..1`
  - changed `InvestorName: Text500Type, 1..1 → Text500Type, 0..1`
- `LoanType`
  - added `FundRole (inline type, 1..1)`
  - added `StartDate (date, 0..1)`
  - added `PayableOnDemand (boolean, 0..1)`
- `NamesType`
  - changed `PreviousName: Text500Type, 0..1 → inline type, 0..1`
- `PortfolioType`
  - changed `Earnings: EarningsType, 0..1 → inline type, 0..1`
- `ShareClassType/Flows`
  - added `@from (date, optional)`
  - added `@to (date, optional)`
- `TransactionType/CorporateAction`
  - added `CorporateActionDocument (inline type, 0..1)`
- `TransactionType/CorporateAction/from`
  - added `AssetUniqueID (inline type, 0..1)`
- `TransactionType/CorporateAction/to`
  - added `AssetUniqueID (inline type, 0..1)`
- `TransactionsType`
  - added `@from (date, optional)`
  - added `@to (date, optional)`
