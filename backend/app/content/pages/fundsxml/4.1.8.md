FundsXML 4.1.8 was published on 2020-11-16 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.8) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 192, **simple types:** 45, **global elements:** 1

## Changes since FundsXML 4.1.7

**New types:** `BenchmarkDynamicDataType`, `BenchmarkProviderCompany`, `BenchmarkStaticDataType`, `BenchmarkUsageType`, `CompanyListedClassificationType`, `PrivateEquityType`

### Changed content models

- `AssetDetailsType`
  - added `PrivateEquity (PrivateEquityType, 1..1)`
- `AssetType`
  - added `IsInfrastructureInvestment (boolean, 0..1)`
- `CompanyType`
  - added `OtherClassification (inline type, 0..*)`
- `FundDynamicDataType`
  - added `Benchmarks (inline type, 0..1)`
- `FundStaticDataType`
  - added `Benchmarks (inline type, 0..1)`
- `LoanType`
  - added `InterestRate (decimal, 0..1)`
- `PositionType`
  - added `PrivateEquity (inline type, 1..1)`
- `PositionType/Certificate`
  - added `Price (FundAmountType, 0..1)`
- `SIIPositionType_V5`
  - changed `InstrumentCIC: CICCodeType, 1..1 → inline type, 1..1`
  - changed `GroupID: string, 0..1 → inline type, 0..1`
  - changed `InstrumentName: string, 1..1 → inline type, 1..1`

### Changed code lists (enumerations)

- `AssetTypeType`: added `PE`
- `ListedIdentifierType`: added `PRIVATE EQUITY ID`
