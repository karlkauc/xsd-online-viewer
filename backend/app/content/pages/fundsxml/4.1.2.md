FundsXML 4.1.2 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.2) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 178, **simple types:** 41, **global elements:** 1

## Changes since FundsXML 4.1.1

### Changed content models

- `EMTFinancialInstrumentType`
  - changed `CostsAndChargesExPost: inline type, 1..1 → inline type, 0..1`
- `EMTFinancialInstrumentType/CostsAndChargesExAnte/Fund`
  - changed `EntryCost: decimal, 1..1 → decimal, 0..1`
  - changed `MaxExitCost: decimal, 1..1 → decimal, 0..1`
- `EMTFinancialInstrumentType/CostsAndChargesExPost/Fund`
  - changed `OngoingCosts: decimal, 1..1 → decimal, 0..1`
  - changed `ManagementFee: decimal, 1..1 → decimal, 0..1`
  - changed `TransactionCosts: decimal, 1..1 → decimal, 0..1`
  - changed `IncidentialCosts: decimal, 1..1 → decimal, 0..1`
- `EMTFinancialInstrumentType/CostsAndChargesExPost/StructuredSecurity`
  - changed `OngoingCosts: decimal, 1..1 → decimal, 0..1`
