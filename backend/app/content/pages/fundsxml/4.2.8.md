FundsXML 4.2.8 was published on 2025-01-31 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.2.8) repository.

- **Main schema:** `FundsXML.xsd` (+ `xmldsig-core-schema.xsd`)
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 271, **simple types:** 58, **global elements:** 1

## Changes since FundsXML 4.2.7

**New global elements:** `CanonicalizationMethod`, `DSAKeyValue`, `DigestMethod`, `DigestValue`, `KeyInfo`, `KeyName`, `KeyValue`, `Manifest`, `MgmtData`, `Object`, `PGPData`, `RSAKeyValue`, `Reference`, `RetrievalMethod`, `SPKIData`, `Signature`, `SignatureMethod`, `SignatureProperties`, `SignatureProperty`, `SignatureValue`, `SignedInfo`, `Transform`, `Transforms`, `X509Data`

**New types:** `CanonicalizationMethodType`, `CryptoBinary`, `DSAKeyValueType`, `DigestMethodType`, `DigestValueType`, `EETReportType1.1.3`, `EETsType1.1.3`, `HMACOutputLengthType`, `KeyInfoType`, `KeyValueType`, `ManifestType`, `ObjectType`, `PGPDataType`, `RSAKeyValueType`, `ReferenceType`, `RetrievalMethodType`, `SPKIDataType`, `SignatureMethodType`, `SignaturePropertiesType`, `SignaturePropertyType`, `SignatureType`, `SignatureValueType`, `SignedInfoType`, `TransformType`, `TransformsType`, `X509DataType`, `X509IssuerSerialType`

### Changed content models

- `CompanyType`
  - added `Type (inline type, 0..1)`
- `ControlDataType`
  - added `CustomAttributes (AttributesType, 0..1)`
- `DirectReportingType`
  - added `EET1.1.3 (EETsType1.1.3, 0..1)`
- `ForeignExchangeTradeType`
  - changed `CurrencyBuy: ISOCurrencyCodeType, 1..1 → inline type, 1..1`
  - changed `CurrencySell: ISOCurrencyCodeType, 1..1 → inline type, 1..1`
- `FundsXML4`
  - added `Signature (ref Signature, 0..1)`
- `PercentageStrategyCoverageType1.1`
  - changed `ConsideredInInvestmentStrategy: EETYesNoType, 1..1 → EETYesNoType, 0..1`
- `SwapType`
  - added `FXRate (decimal, 0..1)`
  - added `AgreedFxRate (decimal, 0..1)`
- `SwapType/Legs/Leg`
  - added `UnderlyingAsset (UnderlyingType, 0..1)`
- `TransactionType`
  - added `OrderExecutionType (inline type, 0..1)`
- `TransactionType/FxSpot`
  - changed `BoughtAmount: SingleAmountType, 1..1 → inline type, 1..1`
  - changed `SoldAmount: SingleAmountType, 1..1 → inline type, 1..1`
- `ValueStrategyCoverageType1.1`
  - changed `ConsideredInInvestmentStrategy: EETYesNoType, 1..1 → EETYesNoType, 0..1`

### Changed code lists (enumerations)

- `CompanyListedClassificationType`: added `NACE Rev 2.1`
