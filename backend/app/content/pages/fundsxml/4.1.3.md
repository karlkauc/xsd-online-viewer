FundsXML 4.1.3 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.3) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 178, **simple types:** 41, **global elements:** 1

## Changes since FundsXML 4.1.2

### Changed content models

- `CreditRiskDataType`
  - changed `CreditQualityStep: CQSType, 0..1 → CQSType, 1..1`
- `EMTFinancialInstrumentType/ClientObjectives`
  - changed `SpecificInvestmentNeed: inline type, 0..1 → inline type, 1..1`
- `EMTFinancialInstrumentType/CostsAndChargesExAnte/StructuredSecurity`
  - changed `ExitCostPriorRHP: decimal, 0..1 → decimal, 1..1`
- `EMTFinancialInstrumentType/DistributionStrategy`
  - changed `ExecutionOnly: RetailProfessionalBothNeitherType, 0..1 → RetailProfessionalBothNeitherType, 1..1`
  - changed `ExecutionWithCheckOrNonAdvisedServices: RetailProfessionalBothNeitherType, 0..1 → RetailProfessionalBothNeitherType, 1..1`
  - changed `InvestmentAdvice: RetailProfessionalBothNeitherType, 0..1 → RetailProfessionalBothNeitherType, 1..1`
  - changed `PortfolioManagement: RetailProfessionalBothNeitherType, 0..1 → RetailProfessionalBothNeitherType, 1..1`
- `SIIPositionType`
  - added `AdditionalInformation (inline type, 1..1)`
- `SIIPositionType/CreditRiskData`
  - changed `Covered: inline type, 1..1 → inline type, 0..1`
- `SIIPositionType/DerivativeOrConvertible/UnderlyingInstrument/Valuation`
  - changed `Country: ISOCountryCodeType, 1..1 → ISOCountryCodeType, 0..1`
- `SIIPositionType/QRTPositionInformation`
  - changed `Participation: string, 0..1 → inline type, 0..1`
  - changed `UnderlyingAssetCategory: inline type, 0..1 → inline type, 1..1`
- `SIIPositionType/Valuation`
  - changed `MarketExposureQC: decimal, 0..1 → decimal, 1..1`
  - changed `MarketExposurePC: decimal, 0..1 → decimal, 1..1`
  - changed `MarketExposureWeight: decimal, 0..1 → decimal, 1..1`
- `SolvencyIIPortfolioType/QRTPortfolioInformation`
  - changed `FundCustodianCountry: ISOCountryCodeType, 0..1 → ISOCountryCodeType, 1..1`

### Changed code lists (enumerations)

- `SIICouponFrequencyType`: added `52`
