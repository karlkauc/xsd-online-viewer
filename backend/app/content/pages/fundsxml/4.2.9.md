FundsXML 4.2.9 was published on 2025-07-04 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.2.9) repository.

- **Main schema:** `FundsXML.xsd` (+ `xmldsig-core-schema.xsd`)
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 281, **simple types:** 58, **global elements:** 1

## Changes since FundsXML 4.2.8

**New types:** `CodificationType_V7`, `ContributionToSCRType_V7`, `CreditRiskDataType_V7`, `RedemptionTypeDerivatives`, `RedemptionType_V7`, `SIIIssuerType_V7`, `SIIPositionType_V7`, `SIISecurityCodificationType_V7`, `SolvencyIIPortfolioType_V7`, `TripartiteTemplateSolvencyIIType_V7`

### Changed content models

- `CountrySpecificFundDataATType/OeNB`
  - added `OtherIncomeNonSecurities (AmountType, 0..1)`
  - added `FeesPaidByShareholders (AmountType, 0..1)`
- `IndirectReportingType`
  - added `TripartiteTemplateSolvencyII_V7 (TripartiteTemplateSolvencyIIType_V7, 0..1)`
- `PRIIPSType_V20/EPTV2/CountrySpecificData`
  - added `UK (inline type, 0..1)`
- `PRIIPS_ReportType/CountrySpecificData`
  - removed `UKPRIIPsDataReferenceDate (date, 1..1)`
  - removed `UK (inline type, 0..1)`
- `PRIIPS_V2_NarrativesType/DescriptionPastInterval`
  - added `WasBenchmarkUsed (YesNoType, 0..1)`
- `SIIPositionType_V6/CreditRiskData`
  - changed `(base): extension of CreditRiskDataType_V6 → extension of CreditRiskDataType_V7`
- `SIIPositionType_V6/DerivativeOrConvertible/UnderlyingInstrument`
  - changed `InstrumentCode: SIISecurityCodificationType_V5, 1..1 → SIISecurityCodificationType_V7, 1..1`
  - changed `Redemption: RedemptionType_V5, 0..1 → RedemptionTypeDerivatives, 0..1`
  - changed `CreditRiskData: CreditRiskDataType_V5, 0..1 → CreditRiskDataType_V7, 0..1`
- `SIIPositionType_V6/InterestRateInstrumentCharacteristics`
  - changed `Redemption: RedemptionType_V6, 1..1 → RedemptionType_V7, 1..1`
- `SolvencyIIPortfolioType_V5/Positions`
  - changed `Position: SIIPositionType_V5, 1..* → SIIPositionType_V7, 1..*`
