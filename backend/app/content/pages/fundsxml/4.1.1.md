FundsXML 4.1.1 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.1) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 178, **simple types:** 41, **global elements:** 1

## Changes since FundsXML 4.1.0

### Changed content models

- `EMTFinancialInstrumentType/CostsAndChargesExAnte/Fund`
  - changed `MaxEntryCostItaly: decimal, 1..1 → decimal, 0..1`
  - changed `MaxEntryCostAcquired: decimal, 1..1 → decimal, 0..1`
  - changed `MaxExitCostItaly: decimal, 1..1 → decimal, 0..1`
  - changed `MaxExitCostAcquired: decimal, 1..1 → decimal, 0..1`
- `EMTFinancialInstrumentType/CostsAndChargesExAnte/StructuredSecurity`
  - added `OneOffEntryCost (decimal, 1..1)`
  - removed `OneOfEntryCost (decimal, 1..1)`
- `FundOrShareClassIdentifiersType`
  - changed `LEI: LEICodeType, 1..1 → LEICodeType, 0..1`
  - changed `ISINs: inline type, 1..1 → inline type, 0..1`
- `PRIIPS_NarrativesType`
  - added `CapitalGuarantee (YesNoType, 1..1)`
  - removed `CapitalGarantee (YesNoType, 1..1)`
