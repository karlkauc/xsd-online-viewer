FundsXML 4.1.9 was published on 2021-09-27 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.9) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 195, **simple types:** 46, **global elements:** 1

## Changes since FundsXML 4.1.8

**New types:** `CommercialPaperType`, `EFTReportType`, `EFTType`, `MICCodeType`

### Changed content models

- `AssetDetailsType`
  - added `CommercialPaper (CommercialPaperType, 1..1)`
- `BondType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `CertificateType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `DirectReportingType`
  - added `EFTs (EFTType, 0..1)`
- `EquityType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `FutureType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `OptionType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `PositionType`
  - added `CommercialPaper (inline type, 1..1)`
- `ReposType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`
- `ShareClassDetailsType`
  - changed `StockMarket: string, 0..* → MICCodeType, 0..*`

### Changed code lists (enumerations)

- `AssetTypeType`: added `CP`
