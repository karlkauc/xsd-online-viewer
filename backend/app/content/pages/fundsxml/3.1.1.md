FundsXML 3.1.1 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/3.1.1) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** `http://www.fundsxml.org/XMLSchema/3.1.1`
- **Root element:** `FundsXML`
- **Complex types:** 117, **simple types:** 37, **global elements:** 1

## Changes since FundsXML 3.1.0

**New types:** `FondsStatistikClosedFundType`, `FundIDDataDEType`, `GesamtStatistikKAGBType`, `GesamtstatistikAbsatzType`, `GesamtstatistikBestandType`, `RiesterSparplanType`, `TargetRegionDEType`

### Changed content models

- `CompanyType/CountrySpecificData/DE`
  - added `BVIGesamtStatistikKAGB (inline type, 0..1)`
- `CompanyType/CountrySpecificData/DE/Besparung`
  - changed `RIESTER-Vertraege: SparplanType, 0..1 → RiesterSparplanType, 0..1`
- `CountrySpecificDataDEType`
  - added `StatusInvVermoegen (inline type, 0..1)`
  - added `OrganisationTypeInvVermoegen (inline type, 0..1)`
  - added `PerformanceFeeModel (inline type, 0..1)`
  - added `MasterFund (inline type, 0..1)`
  - added `FeederFund (inline type, 0..1)`
  - added `ETF (inline type, 0..1)`
  - added `SpecificationsClosedEndedFunds (inline type, 0..1)`
- `DomesticForeignTotalType`
  - changed `Domestic: int, 1..1 → decimal, 1..1`
  - changed `Foreign: int, 1..1 → decimal, 1..1`
  - changed `Total: int, 1..1 → decimal, 1..1`
- `FundFactsType/Custodian`
  - added `LEI (LEICodeType, 0..1)`
- `ReportingDE_BVIType`
  - added `GrossSales (inline type, 0..1)`
  - added `GrossRedemptions (inline type, 0..1)`
  - added `GrossSalesByShare (decimal, 0..1)`
  - added `TotalAmountDistribution (decimal, 0..1)`
  - added `GrossAssets (decimal, 0..1)`
  - added `ClosedEndedFundsEquityIncrease (inline type, 0..1)`
  - removed `ExchangeRates (inline type, 0..*)`
- `ReportingDE_RealEstateType/DetailsRealEstateFunds`
  - changed `EquityCommitments: decimal, 0..1 → inline type, 0..1`
