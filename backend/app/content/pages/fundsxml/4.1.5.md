FundsXML 4.1.5 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.5) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 177, **simple types:** 41, **global elements:** 1

## Changes since FundsXML 4.1.4

### Changed content models

- `AssetDetailsType`
  - added `Commodity (inline type, 1..1)`
- `AssetType`
  - added `FISN (inline type, 0..1)`
- `FundStaticDataType`
  - added `PortfolioManagers (inline type, 0..1)`
- `PositionType`
  - added `Commodity (inline type, 1..1)`
- `ShareClassType`
  - added `RegistrationCountries (inline type, 0..1)`
  - added `SubscriptionRestrictions (inline type, 0..1)`
  - added `RedemptionRestrictions (inline type, 0..1)`
  - added `MarketPlaces (inline type, 0..1)`

### Changed code lists (enumerations)

- `AssetTypeType`: added `CO`
