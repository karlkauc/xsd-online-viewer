FundsXML 4.1.4 was published on 2020-03-25 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.1.4) repository.

- **Main schema:** `FundsXML.xsd`
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 177, **simple types:** 41, **global elements:** 1

## Changes since FundsXML 4.1.3

**Removed types:** `SIIIssuerCodificationType`

### Changed content models

- `CreditRiskDataType`
  - changed `StateGuarantee: YesNoL1Type, 1..1 → YesNoL1Type, 0..1`
  - changed `CreditQualityStep: CQSType, 1..1 → CQSType, 0..1`
- `PositionType`
  - added `PriceDate (date, 0..1)`
- `PositionType/Loan`
  - added `Price (FundAmountType, 0..1)`
- `SIIIssuerType`
  - added `CodeType (inline type, 1..1)`
  - changed `Code: SIIIssuerCodificationType, 1..1 → LEICodeType, 0..1`
- `SIIPositionType`
  - changed `HedgingRolling: YesNoL1Type, 0..1 → inline type, 0..1`
- `SIIPositionType/AdditionalInformation`
  - changed `InfrastructureInvestment: inline type, 1..1 → inline type, 0..1`
- `SIIPositionType/QRTPositionInformation`
  - changed `CollateralisedAsset: YesNoL1Type, 0..1 → inline type, 0..1`
