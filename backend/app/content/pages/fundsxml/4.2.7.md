FundsXML 4.2.7 was published on 2024-10-13 in the [fundsxml/schema](https://github.com/fundsxml/schema/releases/tag/4.2.7) repository.

- **Main schema:** `FundsXML.xsd` (+ `xmldsig-core-schema.xsd`)
- **Target namespace:** none
- **Root element:** `FundsXML4`
- **Complex types:** 247, **simple types:** 55, **global elements:** 1

## Changes since FundsXML 4.2.6

**New types:** `CryptoType`, `EMTType_V42`, `EMT_V42_FinancialInstrumentType`, `IBANType`

### Changed content models

- `AccountType`
  - added `IBAN (IBANType, 0..1)`
- `AssetDetailsType`
  - added `Index (IndexType, 1..1)`
  - added `Crypto (CryptoType, 1..1)`
- `AssetType`
  - added `InfrastructureInvestmentType (inline type, 0..1)`
- `DirectReportingType`
  - added `EMT_V4_2 (EMTType_V42, 0..1)`
- `IndexType`
  - added `IndexProvider (CompanyType, 0..1)`
  - added `Category (inline type, 0..1)`
  - added `Region (inline type, 0..1)`
  - added `Size (inline type, 0..1)`
  - removed `SourceCompany (CompanyType, 0..1)`
  - removed `Market (anyType, 0..1)`
- `RealEstateType`
  - added `UsableArea (positiveInteger, 0..1)`
  - added `Address (AddressType, 0..1)`
  - added `LocationType (inline type, 0..1)`
- `RealEstateType/TypeOfUse`
  - added `ESRB (inline type, 0..1)`

### Changed code lists (enumerations)

- `AssetTypeType`: added `CR`, `IX`
